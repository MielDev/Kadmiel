## 🛠 Installation en local

1. **Prérequis** :
   - Serveur web (Apache, Nginx, etc.)
   - PHP (si nécessaire pour certaines fonctionnalités)

2. **Cloner le dépôt** :

   ```bash
   git clone [URL_DU_DEPOT]
   ```

3. **Ouvrir le projet** :
   - Placez les fichiers dans le répertoire de votre serveur web local (par exemple, `htdocs` pour XAMPP)
   - Accédez à `http://localhost/Kadmiel` dans votre navigateur
